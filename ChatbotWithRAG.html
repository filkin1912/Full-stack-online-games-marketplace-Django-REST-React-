3) Main Concrete Components

  • api_views.ChatbotAPIView.post() - main authenticated chatbot endpoint.
  • api_views.clear_chat_memory() - calls services.clear_memory() to remove ChatMemory rows.
  • models.ChatMemory - stores per-user key/value preferences extracted from user text.
  • models.GameEmbeddingChunk - stores one embedding vector chunk per GameModel (pgvector).
  • services.ask_llm() - orchestrates memory + RAG + fallback + OpenRouter call.
  • rag.ingest.sync_all_games() - rebuilds embeddings for all games via management command.
  • rag.retrieve.retrieve_shop_games() - top-k semantic retrieval using CosineDistance.
