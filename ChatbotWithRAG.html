GamesPlay Chatbot with RAG

Visual guide — RAG flow, vector storage, and full-stack architecture (target design)

RAG Implemented today RAG path = planned pgvector on PostgreSQL

★ RAG in one sentence

Search first, then generate. Turn data into chunks → store vectors → on each question find the closest chunks → send only those to the LLM (not the whole catalog).

Each row = one text chunk + one list of floats (embedding). The DB finds rows closest to the question vector — like a smart filter, not a 2D image matrix for training.
